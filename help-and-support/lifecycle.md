# Product lifecycle

Access Manager support dates are driven in part by the end of support dates for Microsoft .NET.

| Access Manager Version | Status        | .NET version | End of support date |
| ---------------------- | ------------- | ------------ | ------------------- |
| 1.0                    | Not supported | 3.1          | Dec 13, 2022        |
| 1.1                    | Not supported | 6.0          | Nov 12, 2024        |
| 2.0                    | Not supported | 6.0          | Nov 12, 2024        |
| 2.1                    | Supported (maintenance) | 8.0          | Nov 10, 2026        |
| 3.0                    | Supported (maintenance) | 8.0          | Nov 10, 2026        |
| 3.1                    | Supported               | 10.0         | Nov 14, 2028        |

## Support statuses

* **Supported** — the current release. Receives new features, enhancements, and security fixes.
* **Supported (maintenance)** — receives security and critical stability fixes only, until its end of support date. Upgrade to the current release to receive new features and enhancements.
* **Not supported** — no longer receives updates or fixes of any kind.

## End of support

When a version reaches its end of support date, it no longer receives updates or security fixes. The software continues to run after this date, but issues found after that date will not be fixed. Upgrade to a supported version before the end of support date. See [Upgrading to Access Manager v3.1](../installation/upgrading-from-v3.0.md) for upgrade guidance.
